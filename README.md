## ❧ The Invitation

A personal portfolio reimagined as a **Regency estate** in the style of *Bridgerton* — dusty Wedgwood blue, ivory parchment, gilded gold filigree, and a little pixel lady who keeps the house. Every section is a *room* you wander through, from **The Foyer** to **The Correspondence**.

Built as a single, self-contained `.html` file. No frameworks, no build step, no dependencies — just open it and the curtains part.

## ✿ Notable Flourishes

- **Curtain loader** — velvet theatre curtains part to reveal the estate
- **Candlelight mode** — a moon toggle that dims everything into a warm, candlelit evening
- **String-quartet toggle** — a gentle waltz, synthesised live with the Web Audio API (off by default)
- **Project deep-dives** — tap a work to open a gilded modal with live and source links
- **Sparkle cursor trail** — gold sparkles and petals drift behind the pointer
- **Pixel companion** — a hand-drawn pixel lady who curtsies and greets you
- **Request my Card** — a wax-sealed button that downloads the résumé, embedded right in the file
- **A hidden secret** — *tap the gold bee three times and watch closely…*

---

## ⚜ Built With

- **HTML5 · CSS3 · Vanilla JavaScript** — no frameworks
- **Inline SVG** — every ornament, the bee crest, and the pixel lady
- **CSS custom properties** — one palette drives the whole estate (and candlelight mode)
- **Web Audio API** — the live string-quartet waltz
- **Base64-embedded PDF** — the résumé travels inside the single file
- **Google Fonts** — *Cormorant Garamond*, *EB Garamond*, *Pinyon Script*

## ❦ Run It Locally

```bash
# clone the estate
git clone https://github.com/jznica/the-estate.git
cd the-estate

# open the doors (any of these works)
open jenica-estate-portfolio.html      # macOS
start jenica-estate-portfolio.html     # Windows
xdg-open jenica-estate-portfolio.html  # Linux
```

No installs, no `npm`, no build. It is one file.

### Deploy

Drag the folder into **Vercel** or **Netlify**, or push to a **GitHub Pages** branch — it is live immediately.
